# DSA Thực nghiệm các giải thuật sắp xếp nội

## Mô tả
Thử nghiệm các **thuật toán sắp xếp** trong Python với các bộ dữ liệu lớn.  
Bao gồm:

- `sinhtest.py`: Sinh bộ dữ liệu thử nghiệm gồm 10 dãy số (1 triệu phần tử mỗi dãy).  
  - Dãy 1: Float tăng dần  
  - Dãy 2: Float giảm dần  
  - Dãy 3–5: Float ngẫu nhiên  
  - Dãy 6–10: Int ngẫu nhiên  

- `main.py`: So sánh thời gian thực thi của các thuật toán sắp xếp:  
  - Quick Sort  
  - Heap Sort  
  - Merge Sort  
  - NumPy Sort
